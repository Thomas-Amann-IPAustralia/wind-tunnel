Prototype Limitations & Disclaimer

This is an interactive user interface demonstration (Proof of Concept) for the Workflow Discovery AI Agent. It is entirely self-contained and operates with simulated logic. Please note the following limitations:

  • No Real AI Engine: The conversational agent does not use a live Large Language Model (LLM). All interview responses, flags, and nudges are pre-scripted simulations.
  • No Database Integration: No data is saved to or retrieved from real case management systems, ERPs, or internal knowledge bases. All session data is stored temporarily in browser memory.
  • Static Visualizations: The process map is a pre-rendered SVG diagram illustrating the concept of consensus vs. friction, and does not dynamically update based on custom text inputs.
  • No Real Authentication: The role switcher simulates different user perspectives (SME vs. BA/Manager) without security controls or real user profiles.
